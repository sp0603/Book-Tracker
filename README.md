# BOOK TRACKER APP

This repository contains the code required to run the book tracker app. This application allows the user to keep track of the current and future books they are currently
reading or will want to read in the future!

## Getting Started

You will need the following:

- .NET SDK
- Angular CLI

To install angular:

```
npm install -g @angular/cli
```

Then confirm: 

```
ng version
```
## Run the project in this order

```
cd BookTracker.Api/
dotnet build
dotnet run
```
Then

```
cd book-tracker-app/
ng serve
```
